ブラウザで使う基本操作をまとめています。画面に表示される機能は、参加しているチャンネルや設定によって異なります。

ログインとチャンネル

  1. 管理者から案内されたURLを開き、ユーザーIDとパスワードでログインします。「パスワードを表示」で入力を確認できます。ログインに失敗するとフォーム内に理由が表示されます。
  2. 「公開チャンネル」「非公開チャンネル」から閲覧するチャンネルを選びます。狭い画面では、画面上部の一覧アイコンからチャンネル一覧を開きます。
  3. チャンネルが多い場合は一覧上部の検索欄で名前・IDを絞り込めます。検索中は折りたたんだ一覧も開きます。検索欄を空にするか、検索欄でEscを押すと元の一覧に戻ります。未読バッジは検索にかかわらず公開・非公開それぞれの全チャンネルの合計です。
  4. 未参加の公開チャンネルへ投稿するときは、画面上部の「チャンネルに参加」を押します。退出するときは「チャンネルを退出」を押します。

非公開チャンネルは管理者が参加者を設定します。グループ経由で参加している場合は、個人の参加操作だけでは退出できません。

投稿・返信・リアクション

  • 参加中のチャンネルで本文を入力し、「送信」を押します。Enterは改行、Ctrl+Enterは送信です。太字・下線などは入力欄のボタンを使います。
  • 相手に知らせたいときは「@」から参加者を選びます。グループを選べる場合はグループ全体への通知が可能です。
  • 発言への返事は、その発言の「返信」からスレッドを開いて送ります。返信はチャンネルの本文一覧には並びません。
  • 発言や返信には「了解」「完了」「確認中」「感謝」のリアクションを付けられます。同じボタンでもう一度押すと解除します。
  • 誤投稿は自分の発言の「取り消す」を使います。権限がある場合は「取り消しを戻す」で復元できます。

誤投稿は本人、参加中のチャンネル管理者、閲覧権限のある全体管理者が取り消せます。同じ権限で「取り消しを戻す」こともできます。元の位置に取り消しを表示し、新しい未読投稿は作られません。アンケート・公開済み予定調整も回答後を含めて取り消せます。取り消し中は回答受付を停止し、復元後は元の状態と期限に従います。元データと取り消し・復元の操作履歴は保存されます。訂正が必要な場合は新しく投稿してください。

スレッドとメンション

返信は各発言の「返信」からスレッドを開いて読み書きします。返信本文はチャンネルの時系列には表示されません。未読の返信は通知センターの「参加中スレッド」から確認できます。「参加中の全体」では自分が投稿・返信した会話、「このチャンネル」では選択中チャンネルの未読返信を確認できます。返信欄でも本文と同じ書式を見たまま編集できます。必要な相手には「@」から参加者を名前で検索・選択でき、本文中で @ に続けて名前を入力しても候補が開きます。

チャンネルの「すべて既読にする」とスレッドの既読は独立しています。スレッドを開いたときは最初の未読付近を表示し、画面で連続して読んだ位置まで既読が進みます。途中へジャンプした際は飛ばした返信を既読にしません。「このスレッドをすべて既読にする」で明示的にまとめて既読にできます。

通常投稿とスレッド返信のメンション候補には接続状態を表示します。WebSocket接続が1本以上あるユーザーの一文字表示は緑になり、候補を開いている間も状態が更新されます。「接続中」は操作中や即答可能であることを示しません。グループ経由で参加しているユーザーも個別にメンションできます。

通知と既読

  • チャンネル一覧の件数で新着を確認します。まとめて処理するときはチャンネルの「すべて既読にする」を押します。
  • 右上のベルから「通知」「参加中スレッド」「メンション」を確認できます。
  • OS通知を利用する場合は通知センターの「OS通知を有効にする」を押します。接続元やEdge管理設定の詳細はブラウザAPIを使ったOS通知の設定を参照してください。
  • 古い発言についた新しい返信は、通知センターの「参加中スレッド」で「このチャンネル」を選ぶと確認できます。

メッセージ投稿が保存されると、投稿者の既読位置はそのメッセージまで進みます。投稿前に残っていた同じチャンネルの未読も、この時点で既読になります。

接続が切れると画面は2秒後に再接続し、取り逃した投稿を取得します。別チャンネルの通知はチャンネル一覧の新着件数として表示します。

アンケート

チャンネル参加者は入力欄の「＋ 作成」から匿名アンケートを公開できます。質問、2～10件の選択肢、単一／複数選択、任意の締切を設定します。アンケートカードから回答でき、受付中は回答を変更できます。集計には回答者数、各選択肢の票数と割合を表示します。複数選択の割合は回答者数を分母とするため、合計が100%を超えることがあります。回答者名は画面とAPIに公開されませんが、重複防止と回答変更のため保存データには回答者IDを保持します。

受付中のアンケート・予定はチャンネル情報に表示します。アンケートはその場で展開して回答でき、予定は詳細画面を開けます。終了した項目はチャンネルの会話履歴から確認します。

予定調整

左サイドバーの「予定調整一覧」から一覧を新しいタブで開けます。作成するときはチャンネル入力欄の「＋ 作成」→「予定調整」、または予定調整一覧の「新しい予定調整」を選びます。タイトル、説明、2～50件の候補日時、任意の回答期限を入力し、下書き保存またはチャンネルへの公開を選びます。公開すると元チャンネルへリンクが自動投稿され、リンクは新しいタブで開きます。

一覧は「これから・当日」と「終了した予定」のタブで切り替えます。確定済みは確定日、未確定は最後の候補日の翌日0時（日本時間）から終了側へ分類します。当日は時刻を過ぎても通常側に表示します。分類は一覧取得時に行い、データの削除や回答・編集可否の変更は行いません。

作成元チャンネルを閲覧できるログインユーザーが、各候補へ○・△・×とコメントを回答できます。最初の回答後は候補日時が固定されます。作成者またはチャンネルを閲覧できる管理者は、回答の締切・再開と日程確定を行えます。確定結果も元チャンネルへ自動投稿されます。

アカウント

画面左上の鍵アイコンからパスワードを変更できます（管理者が有効にした場合）。同じ欄のログアウトアイコンで終了します。ログインできない場合や非公開チャンネルへの参加が必要な場合は、管理者へ連絡してください。

困ったとき

  • ログインできない：ユーザーIDとパスワードを確認して再入力します。通信エラーの場合はネットワーク接続を確認します。解決しない場合は管理者へ連絡してください。
  • 送信できない：チャンネルへの参加状態と接続状態を確認します。エラーが出た場合は履歴で投稿済みか確認してから再送してください。
  • チャンネルが見つからない：検索欄を空にし、一覧の折りたたみを開きます。非公開チャンネルの参加やアーカイブについては管理者へ確認してください。
  • 新着が反映されない：左上の接続状態を確認し、再接続を待ちます。画面を再読み込みする場合は、入力中の文章を先に控えてください。

管理者向け操作マニュアル

AIを呼び出す

管理者がAIを有効にすると、通常投稿とスレッド返信の入力欄にロボットボタンが表示されます。ボタンからAIを検索・選択し、質問や依頼を書いて送信してください。人へのメンションとは別のボタンです。

通常投稿からはその投稿だけ、スレッドからは親投稿と呼び出しまでの返信をAIへ送ります。取り消された本文は除外します。回答はどちらも呼び出し元のスレッドにAI名とロボット印で表示されます。処理だけを行うAIは回答を投稿しない場合があります。

失敗や送信上限超過はスレッドに理由を表示します。長いスレッドは、短い新規投稿に質問をまとめて呼び出してください。自動再送や再起動後の再開はありません。タイムアウトでも外部処理が実行済みの場合があるため、再度メンションする前に実行状況を確認してください。
