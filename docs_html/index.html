MiniHub ドキュメント

利用者と管理者向けの操作資料です。読みたい資料を選んでください。

  • ユーザー向け操作マニュアル：ログイン、投稿・返信、リアクション、通知、アンケート、予定調整。
  • 管理者向け操作マニュアル：初期設定、HTTP／HTTPS、グループ・ユーザー・チャンネル管理、バックアップと復元。
  • ブラウザAPIを使ったOS通知の設定：利用者の通知設定と管理対象Edgeの設定。
  • 保存方式とSQLiteへの移行：保存方式の選択、停止中の移行、復旧、バックアップ。
  • 投稿の物理削除：保存期間、停止中の実行手順、中断時の復旧。

このフォルダーを丸ごとコピーし、index.htmlをブラウザで開いて閲覧できます。印刷にも対応しています。
